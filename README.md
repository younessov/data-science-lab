# Sparse Matrices and Graph-Based Learning

Academic project — Statistics for Big Data.

## Overview

Study and exploitation of sparse matrices
through Graph-Based Learning techniques.

## Objectives

- Study sparse matrix representations.
- Understand graph theory and graph Laplacians.
- Explore Graph-Based Learning algorithms.
- Implement and evaluate graph learning models.
- Compare dense and sparse approaches.

## Methods

- Label Propagation
- Spectral Graph Learning
- Graph Convolutional Networks (GCN)

## Technologies

- Python
- NumPy
- SciPy
- PyTorch
- PyTorch Geometric
- Jupyter Notebook
